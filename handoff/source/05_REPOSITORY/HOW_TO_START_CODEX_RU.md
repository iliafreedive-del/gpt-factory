# Быстрый старт Codex Cloud

1. Открыть https://chatgpt.com/codex, подключить GitHub и среду `iliafreedive-del/gpt-factory` (main). Убедиться, что среде дан доступ к репозиторию.
2. Приложить этот ZIP к задаче (или загрузить в новый ChatGPT Project для Work). При использовании GitHub без вложений читать `handoff/CODEX_MASTER_TASK.md`, если этот файл появился в репозитории.
3. Вставить короткий запускной промт из файла `CODEX_LAUNCH_PROMPT_RU.txt`.
4. Использовать Codex Cloud, а не локальную задачу, чтобы ноутбук не требовался для работы.
5. Проверять результат по реальным снимкам рендеринга и обновлённому адресу Pages, не только по зелёным галочкам.

Важно: ChatGPT Project/Work и Codex не один интерфейс. Проект хранит файлы и инструкции, Work исполняет многошаговые задачи, Codex Cloud — выделенная облачная среда разработки репозитория.
