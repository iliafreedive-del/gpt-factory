# Завод «Аляска»: контекст передачи

## Что хочет заказчик
Реальную 3D-карту действующего завода легковых прицепов для управления расположением объектов, складской вместимостью, потоками материалов и в будущем моделирования перемещений. Первая законченная очередь — КРАСИВЫЙ И ТОЧНО ОРГАНИЗОВАННЫЙ ЭКСТЕРЬЕР. Не внутренности. Камера с приближением/отдалением. Единицы Godot в метрах, масштаб 1:1. Точная планировка — основа для дальнейших расчётов; не подменять оценочные размеры измеренными.

## Чего нельзя повторять
Ранее ассистент неоднократно давал ложные выводы «готово» по зелёным GitHub Actions, несмотря на ошибки GDScript в логах. Менял по 3–5 деталей и выдавал это за визуальное приближение к референсу. Пытался переносить масштаб на глаз, не использовал реальные измерения полностью. Это вызвало утрату доверия. Нужен end-to-end цикл с реальными рендерами и критическим визуальным сравнением.
