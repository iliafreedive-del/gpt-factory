## Расхождения с текущей BUILD 1.1.3 / MAP 1.1.2

Модель использует общий серый материал западного двора; видео подтверждает конкретное плитное покрытие на показанных участках. Распространять его на всю площадку без сопоставления маршрута нельзя.
Повторяющийся процедурный фасад не передаёт сочетание кирпича, синей/светлой обшивки, полос остекления и низких навесов.
Наружная вентиляция, ворота и плотность хранения рам требуют отдельных деталей; существующие условные пропсы не воспроизводят эти конкретные места.
В кадрах есть и готовые прицепы, и неоснащённые рамы: их нельзя смешивать в один вид складского объекта.
